## Workshop Overview

**Day 1 — Foundation & Productivity** (Labs 01–09)
- Lab 01: CLAUDE.md — Your Enterprise Constitution
- Lab 02: Planning Discipline — Think Before You Build
- Lab 03: Skills & Reusable Workflows — Repo Skills
- Lab 04: Context Management — The #1 Performance Lever
- Lab 05: Hooks — Structural Guardrails
- Lab 06: Bad-Agent Recovery — Catching and Correcting Drift
- Lab 07: Delegated Review — Fresh Context Beats Self-Review
- Lab 08: Parallel Sessions & Isolated Workspaces
- Lab 09: Verification Loops — The Quality Multiplier

**Day 2 — Integration & Governance** (Labs 10–13)
- Lab 10: MCP Servers — Playwright & Browser Verification
- Lab 11: Data Verification — Runtime Data Checks
- Lab 12: Enterprise Governance — Rollout Readiness, Safety Posture & Evidence
- Lab 13: Release-Style Feature Slice

## Three Core Truths

1. Context management is the #1 constraint
2. Planning before implementation is non-negotiable
3. Simplicity beats complexity
