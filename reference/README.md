# Reference Escape Hatches

This folder contains completed lab answers that were removed from the learner
starter.

Use it only when a lab explicitly allows an escape hatch or when you are
blocked and need to compare against a completed slice.

Not every lab has a file-copy rescue. Some chapters intentionally use prompt
reset guidance instead of a completed reference folder when the durable lesson
is about process rather than restoring a code slice.

Available escape hatches:

- `reference/lab01/` — starter and fuller `CLAUDE.md` plus the Region backend slice
- `reference/lab02/` — completed `hireEmployee()` method snippet for the shared employee command repository
- `reference/lab03/` — completed Country/Location backend slices plus cumulative resource wiring guidance
- `reference/lab05/` — layered `.claude/settings.json` with all six hook events wired correctly, for mid-lab recovery if the hand-edited config gets tangled
- `reference/lab06/` — answer keys for the Bad-Agent Recovery lab: annotated transcript with the five planted drift moments and strong-redirect prompt rewrites
- `reference/lab08/` — completed Departments/Jobs frontend pages plus the shell files that expose them
- `reference/lab09/` — completed `promoteEmployee()` method snippet for the shared employee command repository
- `reference/lab13/` — completed Assessments directory frontend page plus minimal router/sidebar wiring snippets
