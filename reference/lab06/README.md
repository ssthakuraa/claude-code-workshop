# Lab 06 Escape Hatch

This folder contains answer keys for Lab 06 (Bad-Agent Recovery).

Use it only when a Lab 06 exercise explicitly tells you to consult it, or when you have spent more than 5 minutes stuck on Exercise 1 or Exercise 4. The point of Lab 06 is to develop your own eye for drift; reading the answer keys before you have done your own pass defeats the lesson.

Available answer keys:

- `transcript-annotated.md` — the same simulated transcript as `lab-materials/docs/lab06-bad-agent-transcript.md`, with the five planted drift moments labelled inline. Answer key for Exercise 1.
- `redirect-prompts.md` — strong-redirect rewrites of the three weak prompts in Exercise 4. Answer key for Exercise 4.

There is no code-restore step in this lab. Lab 06 produces drift inventories, decision cards, and prompt rewrites — none of which need a `reference/` code copy. The CLAUDE.md addition (Recovery Discipline) is small enough that re-typing it from Exercise 6 is faster than restoring a file.

If you consulted either answer key, exit Claude Code and reopen the project so the next lab starts cleanly.
