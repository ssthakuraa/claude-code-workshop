# Environment Setup Prompt

Copy everything inside the box below and paste it into your Claude Code session.

---

```
IMPORTANT — read this before you do anything else:

Do NOT browse, read, list, search, or scan any source code files in this
repository. This is a student lab workspace. Exploring the code before the
exercises will spoil the learning. The only files you are allowed to read are
the ones this prompt explicitly names or that the instructions inside those
files explicitly name.

Please read the file `lab-materials/envsetup.md` and follow every step in it
exactly to set up this workspace.
```

---

That is all you need to paste. Claude Code will read `envsetup.md` and take it
from there. Follow any instructions it gives you — some steps require you to
run a shell command with `sudo` and then tell Claude Code you are done.

When Claude Code says the setup is complete, run this command in a new terminal
from your workspace root to see your setup receipt:

```bash
bash lab-materials/verify-setup.sh
```
